## 목적 충족 판단

코드상 충족한 부분:
- 같은 묶음 안의 자료 전환(웹앱↔학습지)에서 수업 정보는 공유하고, 형태·분량·활동·방법은 따로 저장하고 복원합니다.
- 제작/수정/재개별 정보 조합이 화면 요약과 같은 함수를 씁니다.
- 참고 발췌는 JSON 문자열로 작업 지시와 분리하고, 이름만 있는 자료는 받지 못한 것으로 표현합니다.
- 다른 탭 변경, 손상된 원본, 저장 실패 때 자동 덮어쓰기를 멈추고 이전 형식 키를 보존합니다.

배포 전 수정이 필요한 부분: 차별화의 핵심인 ‘근거·조건 변경’의 신뢰성(P1 1·2·4)과 업무 문서 경로(P1 3)는 현재 상태로는 잘못 표시하거나 맥락을 잃을 수 있습니다.
